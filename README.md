# 棱晶星轨 Crystal Orbit

原创单文件 HTML5 塔防益智游戏。零依赖、零 CDN，打开即玩。

- **在线试玩**：https://game.zhonglike.tech
- **主题**：几何晶体 + 星轨能量的科幻扁平风
- **核心机制**：晶屑不自动入账，必须用「聚能塔」力场收集；相邻聚能塔结成链路，每条链路晶屑价值 +15%
- **内容**：20 关（3 教学 + 中期解锁 + 符文/裂隙/晶屑区谜题 + 双 BOSS）、7 种可升级防御塔、6 种敌人（含克制关系）、三星评价、本地存档
- **操作**：拖拽放置 / 点选放置，桌面 + 移动端自适应

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 部署

推送到 `main` 分支即自动发布到 GitHub Pages（自定义域名见根目录 `CNAME`）。
